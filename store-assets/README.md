# ストア用スクリーンショット生成

iPhone 8 の実機スクショ（750×1334）を素材に、App Store Connect の 6.9 インチ枠
（**1320×2868px**）のマーケ風スクリーンショットを作る。実 UI のキャプチャを
使うため審査規約 2.3.3（スクショは実アプリを反映）に適合する。

生成には **[Open Screenshot Generator](https://openscrgen.app/)** を使う
（完全無料・アカウント不要・ブラウザ内完結で画像はサーバーに送られない・
ストア要求サイズで一括 PNG エクスポート）。

## 手順

### 1. 🧑 実機で撮影 → `store-assets/raw/` に配置

| ファイル名 | 撮る画面 |
|---|---|
| `01-onboarding.png` | 初回オンボーディング（再表示するには アプリ削除→dev build 再インストール か、シミュレータ） |
| `02-camera-ghost.png` | カメラ画面。ゴースト重畳 + シリーズチップ + 情報行が写る構図（被写体は植物などが映えます） |
| `03-series-picker.png` | シリーズ切替シート（2〜3シリーズ作った状態で） |
| `04-gallery.png` | ギャラリー（写真6枚以上ある状態） |
| `05-viewer.png` | 全画面ビューア（共有/削除ボタンが見える） |

### 2. openscrgen.app で合成（🧑 または AI がブラウザ操作で代行可）

1. https://openscrgen.app/ を開き新規プロジェクト作成
2. ストア: **App Store** / デバイス: **iPhone（6.9インチ）** を選択（アートボードが必須寸法になる）
3. アートボードを5枚用意し、`raw/` の画像を順にアップロード → iPhone デバイスフレームに入れる
4. 背景: ブランドグラデ（上 `#0e2a24` → 中 `#123a31` → 下 `#0b1f1a`、角度168°目安）
5. 下のキャプションキットを各スライドに貼り付け（見出し=太字大、サブ=小・白72%）
6. Export → PNG 一括出力 → `store-assets/out/screenshot-1.png` 〜 `-5.png` として保存

### 3. 検証・アップロード

```bash
sips -g pixelWidth -g pixelHeight store-assets/out/screenshot-*.png
# 6.9インチ枠の許容: 1320×2868 または 1290×2796
```

目視確認後、App Store Connect の「6.9インチディスプレイ」枠にアップロード。

## キャプションキット（コピペ用）

| # | 見出し | サブコピー |
|---|---|---|
| 1 | まいにち、おなじ場所から。 | 定点観測をはじめる、いちばんかんたんな方法。 |
| 2 | 前回の写真が、うっすら重なる。 | 同じ画角に合わせて、シャッターを押すだけ。 |
| 3 | 子供の成長も、家庭菜園も。 | シリーズを分けて、まとめて記録。 |
| 4 | 続けるほど、変化が見える。 | シリーズごとに、時系列で振り返り。 |
| 5 | 写真は、端末の中だけ。 | 完全オフライン。共有も削除もその場で。 |

共通フッター的文言（任意）: `ヒビカメ — 定点観測カメラ`

## フォールバック

openscrgen が使えない場合は `template.html`（自作テンプレート、1320×2868 固定）を
`?slide=1..5`（+`&fit=contain`）で開き、Playwright（viewport 1320×2868）で
スクリーンショットを撮る旧方式が使える。キャプションは `SLIDES` 配列で編集。

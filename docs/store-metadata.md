## 3. 説明文（4000字以内）

```
昨日撮った写真を、今日のカメラにそっと重ねて表示。
同じ画角に合わせてシャッターを押すだけで、変化がわかる1枚が撮れます。
「定点観測」を、誰でもすぐに続けられるカメラアプリです。

■ こんな記録に向いています
・観葉植物やお庭の成長記録
・筋トレやダイエットの体型変化
・自宅のリフォームや工事の進捗
・部屋の片付け・断捨離のビフォーアフター
・お子さんの成長記録
・ペットの成長記録

「今日はどのくらい変わったかな」を、毎日同じ角度・同じ距離で撮り続けることで確かめられます。

■ ゴースト機能について
ヒビカメの中心にあるのが「ゴースト機能」です。
前回撮影した写真を、次にカメラを開いたときのプレビュー画面に半透明で重ねて表示します。前回と同じ位置・同じ角度にカメラを合わせるだけで、ズレのない定点観測写真が撮れるようになります。

重ねる写真の透明度は15%・30%・50%の3段階から選べるので、「うっすら目安として使いたい」「しっかり位置を合わせたい」など、好みに合わせて調整できます。

撮影すると、その写真が自動的に次回のゴースト画像として更新されます。特別な設定や操作は不要で、撮るだけで定点観測が続けられます。

■ シリーズ機能について
「子供の成長」「家庭菜園」など、複数の定点観測をシリーズごとに分けて、並行して記録できます。
シリーズはカメラ画面上部のチップをタップするだけでいつでも切り替え可能。ギャラリーには選んでいるシリーズの写真だけが表示されるので、記録がごちゃまぜになりません。
シリーズには名前のほかに「リビング」「ベランダ」などの場所ラベルを任意で付けられ、ゴースト画像と一緒に前回の撮影日時・場所が画面上に表示されます。

■ ヒビカサネについて
たまった写真から「はじまり」と「いま」をふくむ最大4枚を自動で選び、1枚のタイムライン画像にまとめられます。テンプレートはスクラップ・シンプル・フィルムの3種類。できた画像はアプリ内のタブに保存され、共有シートからそのまま家族や友人に送れます。

■ 続けるための仕組み
・撮影リマインダー: 毎日決まった時間に通知でお知らせします（端末内で完結するローカル通知です）
・撮った瞬間、前回の写真から今回の写真へ切り替わるビフォーアフター表示。毎回の変化がすぐわかります
・カメラ画面に「前回から◯日」と連続記録を表示。コツコツ続ける励みになります
・ギャラリーの「くらべる」で、2枚の写真の境界を指でなぞって見比べられます

■ シンプルな画面構成
・カメラ画面: 起動すると、すぐに全画面カメラが立ち上がります。上部のチップでシリーズを切り替え、シャッターボタンを押すだけで撮影完了です。
・ギャラリー画面: 選択中のシリーズの写真を3列グリッドで時系列に一覧表示します。写真をタップすると全画面で確認でき、その場で共有・削除もできます。

■ プライバシーについて（大切なお約束です）
ヒビカメは、撮影した写真をアプリ専用のフォルダに保存するだけのアプリです。

・写真は端末内にのみ保存され、開発者や第三者に送信されることは一切ありません。
・シリーズ名や場所ラベルも、ユーザーが手入力する端末内保存のテキストです。GPSや位置情報は一切使用しません。
・インターネット通信を行わない、完全オフライン動作のアプリです。
・アカウント登録やログインは不要です。
・利用状況を解析する仕組みや広告は入っていません。
・アプリが利用する権限は、カメラと（リマインダーを使う場合のみ）通知だけです。リマインダーは端末内のローカル通知で、外部サーバーを使いません。

大切な記録だからこそ、余計な機能やデータ収集のないシンプルな作りにしました。

■ こんな方におすすめです
・毎日の小さな変化をコツコツ記録したい方
・筋トレやダイエットの成果を写真で振り返りたい方
・植物やペットの成長を見守りたい方
・工事やリフォームの進み具合を記録したい方
・部屋の片付けのやる気を写真で維持したい方
・お子さんの成長を同じ構図で残していきたい方
・子供の成長と家庭菜園など、複数のテーマを同時に記録したい方

昨日の自分と、今日の自分を写真で比べてみませんか。
まずは1枚、シャッターを切るところから始めてみてください。
```

- 文字数: 1,804字 / 4000字（改行含む・v1.1 でヒビカサネ/続ける仕組みの節を追加）

## 7. 審査ノート（Notes for Review）

App Store Connect の「App Review Information」→「Notes」欄に、英語で以下を貼り付けてください。（ASC の上限 4000 字に収まる 3,189 字版。2026-10-11 短縮）

```
HOW TO TEST THE CORE FEATURES

1. Launch the app. First launch shows a one-screen onboarding with a text
   field for naming your first "series" (a named fixed-point observation,
   e.g. "Child's growth"). Tap 「はじめる」 (Start).
2. Grant camera access when prompted (the only permission requested). The
   full-screen camera opens, with a chip at the top showing the active
   series name.
3. Tap the shutter once. The photo is saved only to the app's sandboxed
   local storage, in a folder scoped to the current series.
4. The photo you just took now appears as a semi-transparent "ghost"
   overlay on the live preview, with a caption showing when it was taken
   and the series' optional location label. This is the core feature: it
   lets the user line up the next shot with the previous one for repeat /
   fixed-point photography (plant growth, body changes from exercise,
   renovation progress, a child's growth, etc.).
5. Overlay opacity is adjustable (15% / 30% / 50%) on the camera screen.
6. Tap the series chip to open the series picker. "+ 新しいシリーズ" creates
   another series (name + optional location label); tapping an existing
   one switches to it, and the ghost overlay and gallery switch to that
   series' own photos. The "編集" (Edit) button on each row (or long-press)
   edits its name/label.
7. The gallery thumbnail (bottom right) opens a 3-column, newest-first
   grid showing only the active series' photos.
8. Tap a photo to view it full screen, where you can Share (system share
   sheet) or Delete it.

WHY THIS MEETS GUIDELINE 4.2 (MINIMUM FUNCTIONALITY)

HibiCam is a focused utility for repeat photography / fixed-point
observation: taking photos from the same position over time to visualize
gradual change. Doing this by hand (matching angle, distance and framing
from memory) is hard; the ghost overlay solves exactly that by showing
the previous photo at adjustable opacity directly in the live preview.
Beyond a bare camera, the app offers a complete workflow built around
this one use case: guided onboarding; multiple independent series run in
parallel, each with its own name, optional location label, per-series
ghost overlay and per-series gallery; automatic update of the ghost
reference photo after every shot; and a full-screen viewer with
Share/Delete. We believe this is a small but complete utility, not a
bare-bones camera clone or a wrapped website.

DATA COLLECTION / ACCOUNTS

- No account, sign-up, or login of any kind.
- Zero data collection: no analytics or ad SDKs, fully offline. The only
  outbound action is the "プライバシー" (Privacy) link in the gallery
  header, which opens our privacy policy page in the external browser.
- Photos are stored only in the app's sandboxed local storage and are
  never uploaded or synced. A photo leaves the device only when the user
  explicitly taps Share and picks a destination in the system share
  sheet.
- Series names and location labels are freeform text typed by the user,
  stored locally (series.json). No GPS / Core Location is used - the
  "location label" is just a user-chosen text tag (e.g. "Living room").
- The only permission requested is Camera.

NOTE FOR RESUBMISSION (build 3)

- The flagged NSMicrophoneUsageDescription has been REMOVED from the
  binary: the app never uses the microphone (photo-only camera).
- This build also adds "Hibikasane": a one-tap feature that composes a
  series' photos (oldest / evenly spaced / latest, up to 4) into a single
  timeline-comparison image with 3 selectable templates, saved to an
  in-app tab or shared via the system share sheet. Fully on-device, no
  new permissions. The full-screen viewer now also shows the capture
  date and optional location label.

Thank you for reviewing HibiCam.
```

## 8. App Privacy（プライバシー情報）申告メモ

App Store Connect の「App Privacy」設問では、**「Data Not Collected（データは収集されていません）」を選択する想定**です。根拠は以下のとおりです。

- アプリ内にネットワーク通信を行うコードが存在せず、外部サーバーへのデータ送信経路自体がない（完全オフライン動作）。
- 解析SDK（Firebase Analytics 等）・広告SDK・クラッシュレポートSDKなど、外部にデータを送信するライブラリを一切組み込んでいない。
- ユーザー登録・ログインの仕組みがなく、氏名・メールアドレス・ユーザーIDなど個人を識別する情報を扱っていない。
- 撮影した写真はアプリ専用のローカルストレージ（サンドボックス内のドキュメントディレクトリ）にのみ保存され、開発者のサーバーやサードパーティに送信されることはない。
- シリーズ名・場所ラベルは、ユーザーが任意で手入力する端末内保存のみのテキストです。GPSや位置情報APIは一切使用しておらず、緯度経度等の位置情報を取得・保存することはありません。
- 利用者が明示的に「共有」を選択した場合のみ、OS標準の共有シートを通じて写真が端末外に渡る可能性があるが、これは開発者・アプリ側が収集・取得する処理ではなく、利用者自身が都度選ぶ操作であるため、アプリによる「データ収集」には該当しない。
- 要求する権限はカメラのみで、位置情報・連絡先・マイクなど他の権限は一切要求していない。

上記より、写真データ（Photos or Videos）を含め、いずれのデータカテゴリについても「収集してアプリの機能に紐づけて利用する」実態が存在しないため、「Data Not Collected」の選択が妥当と判断しています。

申告時は念のため、審査提出直前のビルドで以下を再確認してください。
- ネットワーク権限（App Transport Security 設定や通信コード）が実装に追加されていないか。
- 解析・広告SDKが依存関係（package.json 等）に混入していないか。

v1.1 補足: 撮影リマインダー（expo-notifications）は端末内で完結するローカル通知のみで、プッシュサーバーやデバイストークンの送信は行わないため、「Data Not Collected」の申告は変わりません。
